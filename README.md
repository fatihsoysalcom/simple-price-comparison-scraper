# Simple Price Comparison Scraper

This Python script demonstrates a basic web scraping technique to extract product prices from URLs. It uses the `requests` library to fetch web page content and `BeautifulSoup` to parse HTML and find price information, illustrating the core concept of automated price comparison.

## Language

`python`

## How to Run

1. Make sure you have Python installed.
2. Install required libraries: `pip install requests beautifulsoup4`
3. Replace placeholder URLs in the script with actual product page URLs.
4. Run the script: `python price_scraper.py`
